# מחשבון מס הכנסה 🧾

מחשבון מס הכנסה חודשי לפי מדרגות המס בישראל לשנת 2026.

## תכונות

- **חישוב מדרגות מס** — פירוט מלא לפי 7 מדרגות המס (10%–50%)
- **נקודות זיכוי** — ברירת מחדל 2.25 (תושב ישראל + שכיר), ניתן לשינוי
- **זיכויי מס נוספים:**
  - פנסיה (חלק עובד) — זיכוי 35%
  - קרן השתלמות — הפחתה מהכנסה החייבת עד תקרה
  - תרומות (סעיף 46) — זיכוי 35%
- **ביטוח לאומי ומס בריאות** — חישוב אוטומטי לפי שיעורי 2026
- **יצוא תוצאות** — הדפסה/PDF ו-CSV לאקסל
- **ממשק עברי** (RTL) — מותאם למובייל

## שימוש

פתח את `index.html` בדפדפן — אין צורך בשרת או התקנות.

```
index.html   ← קובץ יחיד, כולל HTML + CSS + JavaScript
```

## חישוב המס

1. מזינים משכורת ברוטו חודשית
2. אופציונלית: מוסיפים פרטים מהתלוש (פנסיה, קרן השתלמות, תרומות)
3. לוחצים **חשב מס**
